# HR-analytics-Dashboard-


HR Analytics Dashboard
This project is a descriptive analysis of historical employee data to understand why employees, especially freshers, leave the company.

📊 Key Insights
Freshers tend to leave primarily due to low salaries.

Male employees have a higher attrition rate compared to females.

Attrition patterns vary across salary, education, age, and job roles.

🛠 Tools & Technologies
Power BI – Dashboard creation & data visualization

Excel – Data cleaning & preparation

DAX Queries – Advanced calculations & KPIs
